화면

Mutelink자신의 목소리 대신 원하는 목소리로 VRChat에서 대화하세요.

목소리를 내지 않는 사용자를 위한 VRChat 대화 도구 (Windows, 앱 무료)

다운로드
시작하기
BOOTH (후원판)

말을 글로

PC 또는 클라우드 음성 인식, 키보드, VR 키보드로 글을 입력할 수 있습니다.

목소리와 채팅창으로 전달

VOICEVOX, Irodori-TTS, Qwen3-TTS(10개 언어)로 읽고 VRChat 채팅창에도 보낼 수 있습니다.

번역해서 전달

일본어로 말하고 영어 등으로 번역해 보낼 수 있습니다. 번역은 PC 안에서 또는 Azure로 처리합니다.

상대의 말 읽기

VRChat의 소리를 인식하여 상대의 말과 번역을 글로 보여 줍니다.

VR 안에서 사용

VR 키보드, 컨트롤러 단축키, 손이나 시야에 놓는 패널을 제공합니다.

자신의 목소리도 사용

버튼 하나로 자신의 목소리를 그대로 전달할 수 있습니다.

이 사이트에 대해 ​

앱 설정 오른쪽 위의 “?”를 누르면 각 설정의 설명이 표시됩니다. 이 사이트에는 앱 안에서 보여 주기 어려운 자료를 모았습니다.

  • 설치 전 안내: 시작하기, 후원판, 개인정보
  • 비교 자료: 목소리 비교, 음성 인식 엔진 비교, 번역 엔진 비교
  • 자세한 설정 안내: Azure Translator 설정
  • 문제가 생겼을 때: 문제 해결, Q&A

필요한 것 ​

  • Windows 10/11
  • VRChat
  • VB-Audio Virtual Cable(무료): 합성 음성을 VRChat 마이크로 보내려면 필요합니다. 채팅창만 사용한다면 필요하지 않습니다.
  • Vulkan 지원 GPU(선택): Irodori-TTS와 Qwen3-TTS에 필요합니다. VOICEVOX는 GPU 없이 작동합니다.
  • SteamVR(선택): VR 화면과 컨트롤러 조작을 사용할 때만 필요합니다.

동작 확인 환경 ​

개발자가 동작을 확인하는 환경입니다. 이보다 낮은 사양에서는 동작을 보장하지 않습니다.

  • OS: Windows 11
  • GPU: NVIDIA GeForce RTX 4070
  • CPU: AMD Ryzen 7 7700
  • 메모리: 32GB(DDR5)
  • 헤드셋: Meta Quest 3(PCVR)
