Translation engines ​

Choose from three translation engines. All outputs for the same sentences between English and 28 languages are available. Read the outputs for your languages before choosing.

Choosing an engine ​

EngineRuns onSetupText destination
Azure TranslatorCloudYour Azure key (setup); 2 million characters/month freeMicrosoft servers
PLaMo(PLaMo 3 Translate 0.8B)This PCDownload ~0.57GB modelStays local
TranslateGemma(TranslateGemma 4B)This PCDownload ~2.49GB modelStays local
  • Set first-to-third priorities in Settings > Translation. The first engine supporting the language pair and ready to use (key entered or model downloaded) is selected.
  • PLaMo supports a limited set of languages; it is not used for the extremely low-scoring languages below. Unsupported pairs pass to the next engine.
  • Local engines run on CPU or NVIDIA GPU. GPU is faster but shares VRAM with VRChat and speech synthesis.

Suggested reading order:

  1. Select a language below and open both English → that language and that language → English.
  2. Check VRChat terms (instance, avatar), negation, times, numbers and refusals.
  3. Do not choose by score alone. Scores measure character similarity to one reference, not the percentage of correct meaning.

Conditions and limitations ​

  • Results from November 14, 2026, using the same models and settings as the app.
  • Sources and references were AI-authored, without native-speaker review. Wording different from the reference may still be correct.
  • chrF measures character-sequence similarity to the reference (0–100; higher is closer). Correct paraphrases and tone differences can lower it. Do not compare scores across languages.
  • “Output returned” only means a non-empty response, not acceptable quality. Pages also include untranslated English, wrong-language text, repetitions and truncated outputs.
  • Only 30 short conversational sentences were tested. This does not establish performance on long text, names or recognition errors.
  • Translation quality is not guaranteed. Do not rely on it for important conversations.
