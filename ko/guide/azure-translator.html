Azure Translator 설정 ​

Microsoft 클라우드 번역인 Azure Translator를 Mutelink에서 쓰기 위한 키 생성 방법입니다. F0 무료 요금제는 월 200만 자까지 제공합니다.

PC에서 작동하는 PLaMo와 TranslateGemma에는 이 준비가 필요 없습니다. 번역 엔진 비교를 참고하세요.

시작 전 안내

  • Azure 등록에는 주소, 전화번호, 신용카드 인증이 필요합니다. 등록과 인증을 마친 종량제 구독을 준비해야 하며, Microsoft 계정 가입만으로는 완료되지 않습니다.
  • F0 무료 요금제에서는 월 200만 자를 넘어도 요금이 부과되지 않고 그달의 번역이 중단됩니다.
  • 번역할 글은 Microsoft 서버로 전송됩니다(개인정보).
  • Azure 포털 화면과 용어는 바뀔 수 있습니다. 안내와 다르면 비슷한 이름의 항목을 찾으세요.

1. Azure 종량제 구독 준비 ​

  1. Azure 계정 등록 페이지에서 종량제 등록을 시작합니다.
  2. Microsoft 계정으로 로그인하거나 계정을 만드세요.
  3. 주소 등 등록 정보를 입력하고 전화번호·신용카드 인증과 결제 수단 등록을 마칩니다.
  4. Azure 포털의 구독에서 종량제 구독이 생성되고 활성 상태인지 확인합니다.
  5. 무료 계정으로 시작했다면 필요한 경우 업그레이드에서 종량제로 전환하세요.

이미 활성 종량제 구독이 있다면 이 단계는 필요 없습니다.

Azure 종량제와 Translator 리소스의 가격 책정 계층은 별개입니다. 다음 단계에서는 Free F0를 선택합니다. 다른 유료 서비스나 Translator 유료 계층을 사용하면 요금이 발생합니다.

2. Translator 리소스 생성 ​

  1. Azure 포털을 엽니다.
  2. 위 검색창에서 Translator를 찾아 선택하고 만들기를 누르세요(일본어 UI에서는 翻訳ツール).
  3. 다음과 같이 입력합니다.
항목입력할 내용
구독본인 구독(하나뿐이면 그대로)
리소스 그룹새로 만들기를 눌러 원하는 이름 입력(예: mutelink)
지역가까운 지역(예: Japan East). 나중에 이 지역을 Mutelink에 입력합니다
이름리소스 식별 이름(예: mutelink-translator-1234). 이미 사용 중이면 끝의 숫자 등을 바꾸세요
가격 책정 계층Free F0(월 200만 자 무료)
  1. 검토 + 만들기를 누르고 내용을 확인한 다음 만들기를 누릅니다.
  2. 배포가 완료되면 리소스로 이동을 누릅니다.

리소스로 이동을 누르면 Translator 대신 리소스 그룹이 열릴 수 있습니다. 목록에서 만든 Translator를 선택하세요. 바로 보이지 않으면 새로 고침을 누른 뒤 표시된 Translator 이름을 클릭하세요.

Free F0를 선택할 수 없을 때

구독 하나당 무료 Translator 리소스는 하나만 만들 수 있습니다. 이전에 만든 리소스가 남아 있는지 확인하세요.

3. 키와 지역 확인 ​

  1. Translator 화면의 왼쪽 메뉴에서 키 및 엔드포인트를 엽니다. 리소스 그룹에 있다면 먼저 목록의 Translator를 클릭하세요.
  2. 키 1(KEY 1)을 복사합니다.
  3. 위치/지역(Location/Region)의 값(예: japaneast)을 적어 둡니다.

키를 다른 사람에게 보여 주지 마세요

키를 알면 누구나 본인 할당량으로 번역할 수 있습니다. 방송·화면 공유·스크린샷에 노출하지 마세요. 유출되면 같은 화면에서 키 1을 다시 생성하세요.

4. Mutelink에 입력 ​

  1. Mutelink 설정 > 번역을 엽니다.
  2. Azure Translator 항목의 키에 키 1을, 지역에 적어 둔 값(예: japaneast)을 입력하세요.
  3. 번역 테스트에서 번역 결과가 나오는지 확인합니다.
  4. 번역 엔진 우선순위에서 Azure Translator를 원하는 순서에 놓으세요.

키는 이 PC의 설정에만 저장됩니다.

문제 해결 ​

상황확인할 내용
테스트에서 키 오류앞뒤 공백 또는 Translator가 아닌 다른 리소스의 키인지 확인
테스트에서 지역 오류위치/지역의 값을 그대로 입력했는지 확인(Japan East가 아닌 japaneast)
잘 되다가 갑자기 실패월 200만 자를 다 썼는지 Azure 리소스의 메트릭에서 확인
생성 직후 실패사용할 수 있을 때까지 몇 분 걸릴 수 있음

설정 > 번역에는 이 PC의 앱이 번역한 이번 달·오늘·최근 30일의 글자 수가 표시됩니다. 같은 키를 다른 곳에서 쓴 양은 포함하지 않습니다.

사용을 중단할 때 ​

Azure 포털에서 만든 리소스 또는 리소스 그룹을 삭제하고 Mutelink 설정 > 번역의 키도 지우세요.

등록 조건과 가격 계층은 Microsoft의 Azure 계정 안내와 Translator 리소스 만들기를 확인하세요.
