번역 엔진 비교 ​

세 번역 엔진을 선택할 수 있습니다. 영어와 28개 언어 사이의 동일 문장 결과를 모두 공개하므로 사용할 언어의 실제 번역을 읽고 고르세요.

엔진 선택 ​

엔진실행 위치준비글의 전송처
Azure Translator클라우드본인 Azure 키(설정), 월 200만 자 무료Microsoft 서버
PLaMo(PLaMo 3 Translate 0.8B)이 PC약 0.57GB 모델 다운로드외부 전송 없음
TranslateGemma(TranslateGemma 4B)이 PC약 2.49GB 모델 다운로드외부 전송 없음
  • 설정 > 번역에서 1~3순위를 정합니다. 언어 조합을 지원하며 키 입력 또는 모델 다운로드가 완료된 첫 엔진을 사용합니다.
  • PLaMo 지원 언어는 제한되어 아래 점수가 매우 낮은 언어에는 사용하지 않습니다. 미지원 언어는 다음 후보로 넘깁니다.
  • 로컬 엔진은 CPU 또는 NVIDIA GPU로 실행합니다. GPU는 빠르지만 VRChat·읽기와 VRAM을 공유합니다.

권장 확인 순서:

  1. 아래에서 언어를 골라 영어→해당 언어와 해당 언어→영어를 모두 확인하세요.
  2. 인스턴스·아바타 같은 VRChat 용어, 부정, 시각, 숫자, 거절 표현이 정확한지 확인하세요.
  3. 점수만으로 고르지 마세요. 점수는 참고 번역 한 개와의 문자 유사도이며 의미의 정확도 비율이 아닙니다.

지원 언어 검토 및 주의할 번역 예시

비교 조건과 한계 ​

  • 2026년 11월 14일 결과이며 앱과 같은 모델·설정으로 번역했습니다.
  • 원문과 참고 번역은 AI가 작성했고 원어민 검수를 거치지 않았습니다. 참고 번역과 다른 표현도 맞을 수 있습니다.
  • chrF는 참고 번역과 문자 배열의 유사도입니다(0~100, 높을수록 유사). 맞는 의역이나 말투 차이도 감점되므로 다른 언어 간 점수를 비교하지 마세요.
  • “출력 반환”은 비어 있지 않은 글을 받았다는 뜻이며 품질 합격을 뜻하지 않습니다. 영어 원문, 다른 언어, 반복, 잘린 출력도 확인할 수 있습니다.
  • 짧은 대화문 30개 비교입니다. 긴 글·이름·인식 오류가 있는 글의 결과까지 알 수는 없습니다.
  • 번역 품질은 보장하지 않습니다. 중요한 대화에는 사용하지 마세요.
