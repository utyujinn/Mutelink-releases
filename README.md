# Mutelink

**声を出さずに、好きな声で、VRChatで話そう。**
無言勢のための、VRChat 会話ツールです(Windows 用)。

話した言葉(またはキーボードで打った文章)を文字にして、合成音声やチャットボックスで届けます。アプリ本体は無料です。
