Reference audio and voice cloning ​

Hear how Irodori-TTS and Qwen3-TTS reproduce a registered reference voice. Both the reference and generated audio can be played.

The original voice is VOICEVOX:小夜/SAYO. A Japanese WAV exported from Sayo was used on an external cloning site to create Japanese, English, Chinese and Korean references. Those four references were then registered with Irodori and Qwen.

Compare the same sentence using a Japanese reference versus a reference in the output language. Qwen has all 4 reference × 4 output combinations (16); Irodori has Japanese → Japanese (1).

Voice cloning requires the supporter edition. See speech engine comparison for Qwen models and acceleration needed for conversation.

Original Sayo audio ​

The source is a Japanese WAV exported from VOICEVOX:小夜/SAYO (Normal). It was used on an external cloning site to create the following four-language references.

Transcript of the original Sayo audio

Generation settings

Each condition was generated once with seed 41001. Irodori-TTS used 4 steps and the Japanese reference; Qwen3-TTS used 0.6B Base Q8_0 with NVIDIA CUDA. Registration/synthesis servers are the same as the app. Audio was converted to mono 64kbps MP3.

Reference texts mean the same thing, but lengths and pronunciation differ, so differences cannot be attributed to language alone. Compare intelligibility, pronunciation, similarity and noise separately. These samples do not change the existing speed/error-rate aggregates.
