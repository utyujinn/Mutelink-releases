업데이트 기록 ​

주요 변경만 최신순으로 표시합니다. 설치 파일은 Releases에 있습니다.

v2.0.0(2026년 11월 15일) ​

화면과 기능을 크게 개선했습니다.

화면 ​

  • 화면과 조작을 전면 개편했습니다.

읽기 ​

  • Irodori-TTS의 VRAM 사용량을 크게 줄이고 속도를 높였습니다.
  • 일본어 외 9개 언어도 읽는 Qwen3-TTS 추가(목소리 비교).

음성 인식 ​

  • 로컬 인식 모델을 갱신하여 일본어 정확도를 크게 개선했습니다(Parakeet 일본어 TDT, Haas-ja, Qwen3-ASR; 비교).

번역 ​

  • 자신의 말을 번역해 읽거나 채팅창으로 보낼 수 있습니다.
  • 들리는 음성을 번역해 읽을 수 있습니다.
  • PLaMo, TranslateGemma, Azure Translator(클라우드) 선택(비교).

VR 키보드 ​

  • 일본어 4종·중국어 4종·한국어 2종, 영어·기호·템플릿 입력을 지원합니다.
  • 쓸어쓰기 입력을 지원합니다.

기타 ​

  • 상대가 말하는 동안 음성을 내지 않고 기다리는 기능 추가(켜기·끄기 가능).
  • 음성이 시작될 때 채팅창 글을 표시하는 기능 추가(켜기·끄기 가능).
  • 컨트롤 패널을 키보드에서 분리해 손에 부착할 수 있습니다(커스터마이즈 확장 필요).

  • Parakeet·Whisper·Google 인식에서 음성 중복·누락 문제 수정.

  • 업데이트 후 첫 실행 시 변경 사항 표시.
  • 조작 실패 시 오류 표시.
